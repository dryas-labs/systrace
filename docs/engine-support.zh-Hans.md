# 引擎支持政策

[English](engine-support.md) | **简体中文**

Systrace 优先支持并测试 [dryas-labs/OpenSysML](https://github.com/dryas-labs/OpenSysML) 的指定构建。它是基于 [Open-MBEE/OpenSysML](https://github.com/Open-MBEE/OpenSysML) 独立维护的衍生版本，不代表获得上游背书。

## 支持版本与上游兼容性

已测试的引擎版本及源码提交记录在 [config/engine.json](../config/engine.json)。更新分支或合并上游 PR，不会自动升级已安装的引擎，也不能证明新的上游发行版已兼容。

| 引擎                  | 当前支持范围                                                |
| --------------------- | ----------------------------------------------------------- |
| 配置指定的 DRYAS 构建 | 主要集成对象，在 Systrace CI 中进行 Windows 和 Linux 测试。 |
| Open-MBEE 上游构建    | 兼容目标，目前尚不是经过测试、可以直接替换的后端。          |
| 其他构建              | 未验证，当前版本检查可能拒绝使用。                          |

当前适配层检查配置版本与必要能力，部分模型查询依赖 DRYAS 专用 stdio API。不能仅修改预期版本设置，就宣称兼容上游。标准 LSP 互操作及按能力降级是目标，不代表任意上游版本已可用。

未来纳入支持的上游版本，必须通过相应的编辑器、验证和模型查询测试。缺少的可选功能必须明确说明，不能将失败伪装为验证成功。

## 向上游贡献

DRYAS 会持续通过 PR 向上游提交适合上游的修复与通用改进。是否接受、需要哪些修改以及何时发布，由上游维护者决定。产品专用或实验性接口可能在设计成熟前继续保留于下游。

已提交、已合并、已发布、已测试是不同状态。贡献进展记录在引擎仓库中；Systrace 的兼容性由自身测试及构建配置确定。DRYAS 对维护版的支持和发布负责。

## 许可证与分发

保留适用的上游许可证、版权与归属声明。在修改过的上游文件中明确标注修改；Git 提交记录和 SPDX 标识本身不能替代修改声明。分发时保留适用的上游 NOTICE 内容，并另行记录下游变更。

引擎源码采用 Apache-2.0，但内置库有独立条款：源自 OMG 的 SysML/KerML 标准库采用 EPL-2.0，OpenSysML 自有库扩展采用 Apache-2.0。参见引擎的[标准库 NOTICE](https://github.com/dryas-labs/OpenSysML/blob/main/internal/workspace/libs/stdlib/NOTICE)。依赖也需要逐项核对。

当前 VSIX 不包含引擎程序或标准库。未来若捆绑引擎，需要单独完成许可证与声明清单，包括适用的标准库源码提供义务。公开 fork 或提交 PR 均不能替代这些要求。法律文本保留原文，支持政策的译文不改变许可证条款。
